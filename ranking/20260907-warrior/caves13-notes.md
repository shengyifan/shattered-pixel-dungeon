## 结论：先拿免费鳞甲，不用先做铁匠

| 位置 | 实际物品 | 判断 |
|---|---|---|
| **11,16** | **ScaleArmor +0，cursed=false，未鉴定，无刻印** | 优先。当前基础STR15+Might加1=16，正好能正常穿。 |
| **3,15** | MailArmor +0，无咒，未鉴定 | STR14；不如现成鳞甲的长期价值。 |
| **3,16** | MailArmor +0，**cursed=true / AntiEntropy** | 不装备；若捡作材料，必须明确这是反熵诅咒甲。 |

现在是Veteran’s Intuition2 / Runic Transference2。**Scale的cursedKnown=false会阻止直接贴纹章**，但先正常装备会被Veteran2立即鉴定。无敌区建议顺序：捡鳞甲→装备鉴定→从旧皮甲转Seal+1并保留Thorns→再升级。仅转纹章后Scale+1要求STR15；再投入2卷即 **Scale+3，STR14，DR3–20**，显著高于当前皮甲+2的DR2–8。本层又有1卷，若投入第三卷则Scale+4为DR4–24；是否用第三卷由主代理根据后续资源决定。

## 东侧封板房

- 封板 **32,8**；房内无初始敌人或陷阱。
- **Upgrade39,11；Food39,7；IronKey38,7；ParalyticGas37,6。**优先全收，再回去拿甲。

## 东房→鳞甲的短路线

房内收完、火焰确实消退后，回**30,8**；沿y8西行至**25,8**，然后：

`24,9 → 23,10 → 门22,11 → 21,12 → 20,13 → 19,14 → 18,14 → 17,13 → 16,12 → 门15,13 → 14,13 → 13,14 → 13,15 → 门12,16 → Scale11,16`

这条路径避开圆坑，也不经过北侧燃烧废墟；快照中沿途没有敌人。**Purity17,11正压在隐藏StormTrap上**，不可顺手点击去捡。StormTrap会在非solid距离2内放强度20 Electricity，优先跳过这瓶。

## 铁匠当前状态与安全到达

- **Blacksmith3,17；矿洞入口5,16→D13/branch1。**当前`quests.blacksmith`：`type=1(CRYSTAL), given=false, started=false, completed=false, favor=0`，各服务计数0，未接任务、未进矿、零贡献。
- 现在不能用铁匠免费升级。初次重铸/硬化各500贡献、升级1000、锻造2000；未来`smith_rewards`有Scale+1，但它不是当前免费地上甲。拿11,16鳞甲完全无需任务。
- 从鳞甲可经**11,15**收MirrorImage，再**10,15 → 9,15**，搜索揭露**暗门8,15**；入门后只能先走**7,15 → 6,15 → 5,15 → 4,16 → 4,17**到铁匠旁。
