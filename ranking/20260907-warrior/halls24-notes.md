# D24 最后血巢与力量：全走东/北路，隐形离场

本地v3.3.8/code896，只读快照`33d2cd6cebf5`，地图38×44。初入H23,32 HP115/115、L20exp12、STR19、HF3/Cleave2/LD3、Haste3/Evasion3，Heal9/Food2/Water3/Aqua68，Light258/Torch1，Hourglass2+约.55，Leap84，Fire1/4、Frost0/2即将回1。root操作UI，本文件只说明静态路径，动态怪每步重读。

**纠正地图猜测：真正最后DemonSpawner是(28,14)，不是(21,19)。**中央房(22,19)是Piranha，(22,20)是普通Scorpio。此层没有Acidic。必需物资只有最后STR(33,7)、北Torch(29,5)、血巢的保证Healing；不必走西边Eye大殿、中央钥匙/井室或南召唤陷阱房。

## 1. 入口从东边安全绕行，Clair在32,23用

入口23,32→24,31，搜/进暗门25,31→26,30→27,29→28,28→28,27→29,26→30,26→31,26，**NE32,25**，再N32,24→N32,23。

**32,26是隐藏GatewayTrap，严禁自动寻路经过它。**31,26→32,25是可走对角，落点32,25为普通地面；只贴邻陷阱不触发。此前错误把Gateway疑作fork入口：源码确认为本层随机传送陷阱，普通activate只用teleportChar/teleportToLocation，当前transitions仅D23入口与D25出口，未有branch入口。仍按用户范围避踩它。

在**32,23自身格用最后Clairvoyance**。20半径覆盖全部北方必须路径、血巢、力量室、出口，以及Disarming24,6、Geyser23,7、三Explosive18,9/21,10/19,11与暗门24,10/23,8。还包括Gateway32,26。比入口投更完整；不需要为了标南部可跳过房间浪费覆盖。Clair只映射/揭示，不开门，不解除陷阱。

实际后续`355b7446d521` H28,27：第一只Ripper870已生于血巢，当前30,14 WANDERING、target364=(22,9)，可能向北走；到门口前重新核，不能因最初东路空就连走。

## 2. 真血巢在东上方小房

32,23→32,22→32,21→32,20→33,19→34,18→34,17(水)→门34,16→33,15(水)→32,14(水)→31,14→门30,14→29,14，血巢28,14就在西邻。

房内27..29×13..15无陷阱，门30,14之后是东侧水室。用29,14候战、HF、拆巢，出现Ripper先看leap_pos再处理。先杀满120HP血巢并拾保证Healing，再留意已游出去的第一只。当前甲和115HP能应付其普通近战，跳扑不能硬吃。水室32..34×13..15可用Aqua恢复；不要误走实心装饰31,13或34,12。Ripper可能从北边回水室，切实读新pos。

此路径不必接触任何初始Eye或Scorpio。保存四巢全杀证据后再离开。

## 3. 北路最后力量与火把

从血巢出来经门30,14→31,14→32,13(水)→32,12→31,11→门30,11→29,11→28,11→27,11→26,10→25,9→25,8→25,7。

**26,6是木障BARRICADE**，挡着力量房。站25,7（普通不可燃地面）用Fireblast点26,6，源码明确能点燃近身solid/flammable木障；施法者本格被排除，25,7不因邻火燃烧。等木障毁、火量清零，再25,6→26,6→27,6入房。不要直接踏火门。

**别向西踏24,6 Disarming，或23,7 Geyser。**这两个都不是取得力量所需，Clair会揭示；25,6下方25,7/25,8路线安全。不要从23,8暗门绕过去冒险。

房27..34×2..7全为EMPTY_SP不可燃地面，无初始敌/陷阱。取Torch29,5、STR33,7并喝到基础STR20。Honeypot33,5可跳过，已有一罐且背包空间有限。北火把值得拿，为Yog暗拳半血/死亡两次抹光留足两支备用。当前中央房Torch25,20不用再冒险取。

## 4. 隐形短路，避三爆炸和三只Scorpio直接下D25

回力量房出口，按27,6→26,6→25,6→25,7→25,8→25,9→**25,10**。在东侧安全格25,10先喝银色Invisibility，持续20T。之后：

`25,10 → 24,10暗门 → 23,10 → 22,9 → 21,9 → 20,10 → 19,10 → 18,10 → 17,11门 → 16,12 → 15,13出口`

这十步Haste3总5.246T，再下楼约1T，隐形时间余量充分。每步读实际怪和trap状态。**避开18,9、21,10、19,11三颗Explosive**，不走原Scorpio18,11占用格；出口房原Scorpio14,15和15,17也可在隐形中绕过。只走路与开门/楼梯，不攻击、法杖、读卷、投Runestone或Leap，避免主动解除隐形。

由25,10先喝再开24,10，是为了不在北蝎可见范围内先暴露一回合。若有动态Ripper恰占安全路线，先依据新图重算少量邻格，不踏三颗爆炸陷阱硬过；20T足够等待/小绕，但不进行无谓战斗。

**不要从东边直接Leap/Blink瞄Scorpio18,11**：目标被占会回退，某些直线路径会回退到19,11爆炸陷阱。若必须打北蝎，已确认候选Leap落点是19,10，落地邻接18,11且无陷阱，能阻止当下射击；但它可能往17,11门退，惊醒出口房两蝎，当前已有隐形且目标是通关，优先上述不战斗短路。
