# D23 剩余路线：一次 Leap、一次新 Blink 使炼金值得往返

只读规划；快照 `993834bd1f32`：H(11,14) 105/105，Ripper(12,14) 26HP，Combo1。酸蝎(19,21)、北 Eye(25,12)、Scorpio(26,12)仍睡，Spawner(20,26) 120HP、下次孵化约11.66T。Hourglass3+0.173，Leap97.2，Haste3。地图42×45。后续位置/敌意必须按root每动作新存档替换，本文不是连续点击授权。

## 推荐顺序

**眼前 Ripper → Food(13,17) → Spawner → Alchemy → 酸蝎经验药 → 出口。**先拆Spawner防长往返期间持续生魔；先炼金再酸蝎能把Cleansing作为保险。Alchemy新增的一瓶Healing、两颗Aggression、一颗净新增Blink和Cleansing值得一次35充能Leap与一颗新Blink；无需把沙漏4充能耗在往返。

1. 杀当前Ripper后 H(11,14)→(11,15)→(12,16)→Food(13,17)，不踩Storm(14,14)，不穿石像(12,15)。
2. 食物→(14,18)→(15,19)→(15,20)→门(16,21)→(16,22)→(16,23)→门(17,24)→Spawner房。保持酸蝎门(17,20)/(17,22)关闭。拆Spawner(20,26)、处理新Ripper、拾保证Healing。
3. 回门(17,24)→(16,23)→(16,22)→(16,21)→沿x16北行到(16,13)，再门(17,13)→(18,13)→(19,14)→(20,15)→(21,16)→**开门并站(22,16)**。x16竖线没有石像；途中每次新怪先处理。

## 跨坟场的精确安全落点

**去程 HeroicLeap：(22,16)→(26,18)。**实际Ballistica序列为：

`22,16 → 23,17 → 24,17 → 25,18 → 26,18`

中间全是GRASS；(24,17)的墓只是heap，不是solid。终点(26,18)是普通闭门，PASSABLE|SOLID：Leap会碰在门本格而非提前停，落地occupyCell正常开门，途中不花世界回合、不触碰墓。起点门(22,16)必须先正常进入打开，不能从(21,16)跳，那个起点会撞在西门而浪费35。先确认落点和中间无新移动敌人，Leap只回退被占用的终点。

两端对当前北怪的射线已按源码整数Bresenham核实：

- Eye(25,12)→西门(22,16)途中撞实墙(23,14)。
- Eye(25,12)→东门(26,18)途中撞实墙(26,15)。
- Scorpio(26,12)→东门(26,18)途中撞实墙(26,14)。

因此不要在暴露的(23,17)/(24,17)/(25,18)落脚，直接两端跳。**这里仅证明弹道被挡，绝不等于ShadowCaster的FOV被挡。实际Leap落26,18已唤醒北Eye，它会追最后看到的位置，回程不能继续使用初始25,12的位置证明安全。**新快照若怪已离开初始坐标，重新核射线。

东门→(27,18)→(28,18)→(29,19)→(30,20)→(31,20)→门(32,20)→(33,20)→(34,21)→(35,22)→(34,23)→(33,23)→**锁门(32,23)**。用已拾的安全IronKey；内无初始敌/陷阱。拾Healing(28,23)、Energy5(31,26)，接近Alchemy(27,27)。

炼金：Rage→Aggression×2，Teleport→Blink×2，两项0能量；Purity→Cleansing花4，当前3+晶体5−4=剩4。不再做昂贵配方。

**返程沿原路到东门(26,18)，用一颗新Blink投西门(22,16)。**反向实际弹道：

`26,18 → 25,17 → 24,17 → 23,16 → 22,16`

终点闭门可通行、全路径连通，Blink能落门并开门。先看途中没有游走怪；Blink为PROJECTILE，途中敌会截住落点，若有敌物就先处理或改Leap。Blink动作会解除冻结，所以不用额外开沙漏。若不想消耗Blink，第二次Leap同一路径也可，但会多用35甲充能；留一颗Blink足够作为之后被Roots时的逃生工具。

## 回程顺路从北门打酸蝎

西门(22,16)→(21,16)→(20,15)→(19,16)→(19,17)→(19,18)→北门(19,19)，复核酸蝎实际坐标后按halls23-notes.md的**冻结→脚下Blindweed→同格Flame→退19,18→解冻**。约2沙漏充能，去炼金使用Leap/Blink不会损失这份预算。Cleansing留作中酸解危，盲期间≥2格投Hammer/法杖，不接触反酸；Dart/Frost会熄Burning。

杀后拾经验药并喝。Spawner15EXP+Acid14EXP：从当前L18exp40会到exp69，再喝一瓶升L19、exp仍69、HT110；如果额外打其它给EXP的怪则按当时数值变动。PotionExperience加当前maxExp，所以能推进Haste的鉴定进度。

酸房到出口：室内(18,21)→(18,22)→门(17,22)→(16,23)→门(15,23)→(14,23)→(13,23)→(12,24)→(11,25)→(10,26)→出口(10,27)。**别点Mimic(13,24)，别踩Corrosion(12,21)。**可顺拾Levitation(11,27)，不另开支线。

Spawner后回(16,20)，实际还有酸蝎西北门**(17,20)**，不必远绕北门。从(17,20)→酸蝎(19,21)的投射线为(18,21)→(19,21)，无墙。可照原冻结双投方案，之后W退(16,20)。火圈x18..20/y20..22不含门(17,20)，但门随后会被蔓延点燃，先退不站燃门。此路线没有Cleansing保险，眼下两次跳转方案已经使炼金更有价值，故仍首推先炼金。

## 实际出门后 Eye 游走修正

实际Leap成功且无激光伤害，但唤醒Eye777。快照 `8456a6dc18b2`：H32,20 HP90，Eye25,16 HUNTING、seen=false、target仍782=(26,18)、beamCharged=false；它将追到东门后转WANDERING选随机目的地。不要假设会原地等候。新生Eye817在7,11朝19,16移动，也必须留意它后续从迷宫/祭室接近。

返程在离开Alchemy前读所有Eye位置，再到东走廊前检查。分情况：

- Eye远离墓室/东门、两扇门及Blink射线没有占用：原Blink可用；落西门后立即读回，再W21,16让西门关上。若Eye已经墓室内，西门22,16可能在它的新射线上，不能在门上等。
- Eye在墓室内但没有蓄光：可先在27,18冻结、进入26,18，再Blink到22,16（Blink本身会解冻），然后按新计时W21,16关门。未经蓄光的Eye需要先2T蓄力，因此一般有关门窗口，但仍逐动作读`Eye.time − Hero.time`。途中有Eye挡Blink时不要投；Leap忽略中途角色，可替代，但仍只落实际无人的终点且不能在已经快发射时贸然跳到新射线。
- Eye已堵东门/走廊，或已经蓄光且没有明确剩余窗口：优先在熟悉墙角把它单杀，再跨回，不把Blink当可穿怪技能。额外13EXP有助于之后达到L20。

**旧refuge(29,19)只对Eye在(26,18)/(27,18)时可靠**：其到29,19的弹道撞28,19实墙。Eye已经(28,18)时，29,19与它邻接，不能靠该墙格避免攻击；29,19的一步退路也没有可靠单步遮蔽。

如果H29,19、Eye已28,18或29,18蓄光，候选安全落点是**Leap31,20**：Hero路径29,19→30,20→31,20通，而Eye到31,20的线分别撞30,19实墙；旧beam也不经过31,20。Leap只花1T，仍必须确认这1T前的实际beam结算顺序。若Hero30/31,20与Eye同走廊对峙，可Freeze后沿y20到33,20，让32,20门在背后关闭，再解冻；三次Haste3移动总1.574T，只需1沙漏充能。

新Enemy位置优先于所有固定候选，特别是Eye到29,19以后，原27,18→29,19墙角模型已经失效。
