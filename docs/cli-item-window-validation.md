# 物品选择窗口专项

> 文档整理说明：配套的历史验收 JSON 已按用户要求删除；原始运行数据也已清空。本页保留当时的验证说明，旧结构化结果可从 Git 历史查阅，不能作为 CLI.0.9.0 的新验收结果。

平衡符石的武器与护甲两项均通过原流程：打开已知符石→USE→选择普通初始装备→Never mind取消；重新选择→Back取消；再次选择→Speed或Evasion→重新选择→Remove Augmentation。取消与Back均不消耗三枚初始符石；应用和移除各消耗一枚，剩一枚，私有augment字段在对应动作自身完成版本中分别为SPEED/EVASION与NONE。已经具有的强化选项不会被原窗口再次广告。

初态只给普通一级战士添加三枚原StoneOfAugmentation，并复用隔离安静区域；未提高角色数值。之后所有选择和消费均走公开CLI与原游戏回调，后置数据只用于核对结果。英文输出依据当前GameScene模态、完整问题、Cancel与原两项属性选项识别窗口；未知文本、战斗浮字、旧窗口和缺失签名不能借用Evasion或Never mind翻译。

4项公开投影边界单测与2项真实游戏测试通过，GUI中文窗口化，共94次同版本检查。首次实际“算了”“闪避”未译的两项失败保留；不是跳过取消或强行设置augment通过。当前仅覆盖原初始短剑/布甲的两个具名流程，其他物品窗口与背包容量/魔免等变体仍需独立测试。完整原路径和结果见 验证记录（历史 JSON 已删除，可查 Git 历史）。
