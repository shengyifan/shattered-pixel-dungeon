# 英文显示错误与审计错误的边界

> 历史方案说明：CLI.2.0.0 已删除此处的中文反查/旧异常策略。当前 String 来源追踪、独立呈现状态与不可重译历史见 [CLI 2.0 实施记录](cli2-implementation.md)。下文保留原验证语境。


低频幽灵召唤测试出现的AUDIT_UNAVAILABLE实际由连续显示文本翻译失败引起。原异常处理在准备错误响应时再次排空显示队列，下一条未译日志又抛异常，落入审计失败的兜底。它并不是已经证明的SQLite物理故障；原冻结报告保留当时的实际响应。

现在异常处理只先排空保存与结束回执，再持久化该请求原有失败。显示日志仍按原顺序在正常路径及finally处理，后续失败继续保存内部原文和异常并关闭会话。该改动不重放游戏动作，不把已执行后的不确定结果改成成功，不改变真正AuditException的兜底。

真实双库与控制运行端口的回归放入GameLogEventsTest：连续两份未知完整显示只产生一个PUBLIC_TEXT_UNAVAILABLE响应，请求账本为REJECTED，两份完整原文和两条异常留在内部库，公开响应/事件不含原文。5项显示事件、15项会话、11项保存回执及1项英文审计边界共32项通过。真实幽灵对白仍需对应语言资源修复后再补测。
