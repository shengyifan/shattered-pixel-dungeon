# 矮人国王召唤预兆的真实引擎测试

2026-09-09，中文、窗口化，2/2 个隔离场景通过。测试构造召唤前的英雄、国王和四个原生 `Summoning` Buff；之后仅通过公开 CLI 触发原等待、菜单和返回。国王本体暂时麻痹以隔离额外攻击，召唤 Buff 仍按原调度生成原怪物，不使用夹具直接切换结算结果，不计正式通关。

## 公开内容

`summoning_bones`、`summoning_shadows`、`summoning_green_flames`、`summoning_sparks` 分别描述实际画出的骨片、暗影、绿焰与火花。来源是原 `fx()` 已经选择的发射器和实际粒子，使用共用 `CellParticleCue`；公开结构仍只有 `{kind, cell}`。不返回 Buff 的 delay、summon 类、国王 phase 或未来生成结果。

观察器经过当前场景连接、视野、视口、HUD/窗口遮挡和真实 drawable 检查。仅在原发射器仍能发射、符合可见门槛且首粒子尚未出现时等待；不会为墙后或暂停的源等待。停止发射后仍实际画出的尾粒子保留，不能把这类视觉证据等同于“仍在蓄力”。

## 实际验证

- `visual-king`：一次原等待的最终响应中四种提示均存在，四个格子独立；原菜单遮挡后提示消失，原返回后重新可见。随后原 Buff 依次完成，公开观察出现矮人尸群、术士、武僧及魔像。尾粒子保留，正常渲染时间过去后消失；英雄状态不因这段渲染等待改变，公开历史保留已经显示的提示。
- `visual-king-hidden`：墙后四个原生发射器继续运行，公开等待约 0.356 秒完成；当前状态及事件历史都没有泄漏隐藏预兆，隐藏源没有阻塞操作。
- 首轮可见场景只得到三种提示，未通过“四种全可见”的断言。该版将火花放在英雄南侧两格，没有保证测试布置下四格均通过显示门槛。随后仅将测试火花格改至北侧，生产过滤保持不变，重新实测通过；不将这次测试布置失败描述为生产修复。
