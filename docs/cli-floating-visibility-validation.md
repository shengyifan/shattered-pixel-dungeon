CLI.0.8.12 修复通用UI路径读取未绘制浮字全文的缺口。此前UiBridge只用visibleCueText决定是否添加presentation标记，缺标记的数字或可直接翻译文字仍可能通过原text字段公开；空节点和ID也可能泄漏其存在。

现在FloatingText仅在原draw发生时登记，VisualCueCollector在完整GameScene.draw结束后，以实际视口和后来绘制的UI遮挡区域保存可见文字片段。下一帧开始与对象池revive都会清缓存。UiBridge在分配ID、创建节点和聚合父控件文字之前过滤无可见片段的浮字，查询不绘制、不重新布局、不调用战斗getter或推进RNG。默认未启用观察器时不生成额外的文字快照。

部分可见时仅保留真正完整显示的word，并标clipped；边缘半字不还原。没有完整word时不生成空占位节点。新增缓存属于呈现状态，内部快照按原规则记录；它不是存档恢复、Actor状态或隐藏AI信息。原RenderedTextBlock无参纯读方法保持原行为，新增protected重载只供绘制层收紧可见片段。

2026-09-12新实机用原FloatingText的三段初态文字，执行连续三个公开view.pan：画面外→画面内→画面外，无中间查询补等。每次操作自身终态分别为无节点、有314159/warrior/dodged及floating_text标记、再次无节点。私有后置记录证明原对象和原文字一直存在、寿命仍有约28至29秒；隐藏不是靠自然过期取得。15次同版本中文窗口化检查，正常退出0，无截图、键鼠或Computer Use。

三模块测试任务通过，当前共374项（协议8、游戏控制270、桌面96，无失败/跳过；未变化的前两模块复用Gradle测试缓存）。其中61项定向测试覆盖纯读、未绘制、数字/已知/歧义词双世界与ID、部分显示、遮挡、透明度和池复用。实机不扩大宣称全部HUD/部分字形组合都测试过。原天狗隐藏用例只验证visual_cues过滤，其旧UI轨迹不构成通用浮字无泄漏证明，历史说明已相应纠正。
