# Shattered Pixel Dungeon v3.3.8 战士天赋与加点长期指南

## 口径

- 本地提交 `7b8b845a76`，正常无挑战战士稳定通关；机制按执行源码，不盲从文本。
- 战士没有隐藏基础属性加成。全职业初始20HT、10力量、10攻击、5防御；每级+5HT、+1攻击、+1防御，力量不随等级增长。
- T1/T2/T3/T4 从等级2/7/13/21开始，正常总点5/6/8/10；单项上限2/2/3/4。T3必须已选子职业，T4必须已选皇冠护甲能力。
- 神圣灵感给指定阶层额外2点，同一阶层一次，不提高单项上限；点数可留到以后，不会消失。

## 战士初始特性

- 已鉴定破旧短剑、3块投石；布甲附破损纹章；已知治疗药和盛怒卷，所有职业共同已知鉴定卷。
- 破损纹章可携带恰好1级护甲升级：纹章附甲时升级/直接升级纹章，换甲后把+1一起转走。
- 纹章护盾公式：`3 + 2×护甲阶数 + 钢铁意志点数`，不看护甲升级等级。布/皮/链/鳞/板基础5/7/9/11/13。
- 非饥饿伤害令当前HP已<=50%或本击会令`HP+护盾`降到<=50%时，纹章护盾在扣伤前自动触发；基础冷却150。
- 看不到敌人且无角斗士连击持续5回合，剩余护盾结束并按剩余比例退冷却，最多75。低血触发是保险，不主动卖血。
- 纹章必须始终跟随主护甲；换甲前确认纹章、携带+1和可转刻印。

## T1（5点，单项上限2）

- 丰盛一餐：HP<33.4%时进食固定回4/6。与食物大小无关；只在本来需要吃时获利，不为触发浪费食物。第一点高，第二点边际低。
- 老兵直觉：只加速近战武器。+1近战1.75倍、护甲执行代码实际2.0倍；+2近战2.5倍、装备护甲立即鉴定。UI写+1护甲2.5倍与代码不符，以2.0为准。立即鉴定发生在装备后，不能防盲穿诅咒。
- 受衅怒火：任何ShieldBuff被伤害击碎，5回合内下一次物理攻击+3/+5；自然消失不触发。与纹章、液蕴意志、狂暴盾协同。第一点高。
- 钢铁意志：纹章护盾+1/+2，稳定线性，但护甲升阶收益更大。

默认5点：`老兵2、丰盛1、受衅1、钢铁1`。

顺序：等级2老兵1、3老兵2、4丰盛1、5钢铁1、6受衅1。缺血时丰盛提前；若已用只读证据解决装备鉴定，可把老兵第2点改钢铁/受衅，但正常新存档默认老兵2。

## T2（6点，单项上限2）

- 钢铁之胃：投入1点即让普通进食3回合→1回合，进食期间减伤75%；2点免伤100%。仍可能吃到状态；浆果等0回合食物没有免伤窗口。默认1点。
- 液蕴意志：饮/投药剂、魔药、秘药得6.5%/10% HT普通Barrier；力量/经验及衍生物双倍13%/20%；高产炼金物按单件概率折算。Barrier取新旧较大值，不叠加并自然衰减。积极炼金路线强，默认2。
- 刻印转移：1点可转 common+uncommon 普通正面刻印；2点再转魅惑/反魔/荆棘等稀有及诅咒刻印。刻印必须在纹章附甲时刻上；可先刻、保留点数，在拆纹章前补天赋。无目标刻印即时价值0，不盲点。
- 手起刀落：物理武器击杀动作67%/100%不耗回合；近战、投武、武器/附魔归因可，法杖/气体/陷阱/深渊不可。第二点把随机变确定，是T2最高优先，默认2。
- 即兴投掷：向敌人格扔非MissileWeapon物品时致盲2/3回合，冷却50；物品继续正常效果。进攻药可同时触发液蕴护盾+致盲。第一点高，第二点只+1回合；免盲敌仍吃冷却。

无关键刻印默认：`手起刀落2、钢铁之胃1、液蕴意志2、即兴投掷1`。

顺序：7手起1、8即兴1、9钢胃1、10手起2；11-12先等实际刻印：

- 无好刻印：液蕴2。
- 普通好刻印：液蕴1+刻印1。
- 反魔/荆棘/魅惑：刻印2，或刻印2+液蕴1并从钢胃/即兴中让1点。

## 子职业

### 角斗士

- 近战/物理投武每次成功命中+1连击；法杖不加。基础命中后5回合，击杀后15回合。
- 2冲击：必中、0伤、推2并+1连击，普通版主动避免落崖；一次连击中仅1次。
- 4撞击：普通攻击+自身随机DR×连击/5额外伤害，重置。
- 6招架：下一回合首次可闪避攻击必中格挡并反击；未触发则连击清零。环境/无命中判定效果不可假定能挡。
- 8横扫：主目标`25%×连击`武器伤，路径半径3其他敌人一半，重置。
- 10暴雨：连击数次攻击，每次60%，可触发附魔，重置。

T3通用：

- 不动如山：等待后在原地得1-2/2-4/3-6 DR；连击、纹章护盾离敌消散、Barrier/狂暴盾自然衰减速度变50%/25%/0，移动失效。
- 力大无穷：基础力量按8%/13%/18%向下取整。典型基础力量14时+1/+1/+2；16时+1/+2/+2；18时+1/+2/+3。只在能跨装备需求/实际加力阈值时点。
- 连战热忱：击杀后连击保持30/45/60（基础15+每点15）。1点通常够短路线。
- 以战养战：连击战技每杀1敌，纹章盾冷却-50/-100/-150，可降至-150。范围战技多杀可多次触发；要主动用战技收尾。
- 战技强化：1点在7连使冲击推3+眩晕且可落崖；2点在9连使招架挡下一回合所有可闪避攻击；3点让撞击/横扫/暴雨可跳`连击/3`格接敌。

稳定8点：`战技强化2、以战养战3、连战热忱1、不动如山2`。

顺序13强化1、14连战1、15以战1、16强化2、17-18以战2-3、19-20不动1-2。若力量点能立刻跨装备门槛，用力大1替不动1；偏进攻可用`强化3、连战2、以战3`。

### 狂战士

- 仅普通物理攻击链的原始伤害积怒，发生在护甲DR前，因此高甲完全格挡仍可积怒；法术、气体、陷阱等不积。
- 每次加怒约`原始伤害/HT/4`；怒气使物理攻击最高+50%伤。
- 100%且纹章仍附甲时可主动狂暴。盾基础`8+2×护甲强化等级`，再按缺血从1倍到3倍；盾每回合自然失去2.5%且至少1，耗尽后正常主动狂暴恢复100回合。
- 不动如山会减缓/停止狂暴盾自然衰减；伤害消耗仍正常。
- 洪荒之怒：上限116/133/150%；>100不再增伤，但每额外1%提高盾1%、缩短冷却1%。
- 不朽骤雨：HP降0且怒>=100自动狂暴；结束时若HP仍0仍死。恢复需3/2/1英雄等级。1点是安全网，额外点只缩短罕见冷却。
- 怒气导魔：100%怒时武器附魔/诅咒触发倍率1.15/1.30/1.45；无好附魔价值低。

稳定8点：`洪荒3、不朽1、不动3、力大1`；有强附魔用`洪荒3、导魔3、不朽1、不动1`。若高甲/高强化不足、魔法敌多，默认角斗士更稳定。

## T4护甲能力（等级21-30共10点，单项上限4）

- 皇冠把当前护甲保留阶数、升级、刻印、纹章转成职业护甲并给50%充能；自然500回合从0充满。英勇能量1-4使能力耗能减少12%/23%/32%/40%。

### 英勇之跃（默认稳定推荐，基础耗35）

- 跳到指定可达点，越过敌人/陷阱/深渊，但不能越实体/墙；落点正常触发地格。
- 肉弹冲击：邻敌伤`点数~4×点数 + 25%×点数的英雄DR`。
- 堕天一击：邻敌径向推2/3/4/5，25/50/75/100%易伤5。
- 二段跳：使用后3回合内第二次耗能减16/30/41/50%。
- 英勇能量：基础35→约30.8/27.0/23.8/21。

默认最终10点：`英勇能量4、二段跳4、堕天一击2`。优先先点英勇2+二段1：两跳总耗约49.6，刚好不超过职业甲初始50；再补二段4、堕天2、英勇4。高甲输出路线可把部分二段/堕天换肉弹。

### 震地冲击（基础耗35）

- 5格、60度锥形；`5+(STR-10) ~ 10+2×(STR-10)`物伤并残废5；基础不击退。
- 广域：射程6/7/8/9，角75/90/105/120。
- 复合：30/60/90/100%应用攻击Proc；角斗士每命中敌人可加连击；4点另+20%附魔倍率。
- 强力：伤+20/40/60/80%，25/50/75/100%把残废换麻痹5。
- 角斗士清群方案：`复合4、强力2、广域2、英勇2`。

### 苦痛坚忍（基础耗50）

- 立即忍耐3回合，所有伤先记录原始值一半并基础减伤50%；之后10回合内下一次攻击附加所储伤害。补3回合连击时间。
- 持续反击：储存总额×1.15/1.30/1.45/1.60，再分2/3/4/5次攻击。
- 痛觉阈值：总减伤60/68/74/80%。
- 情势反转：结束时两格内每敌使储伤+5/10/15/20%。
- 稳定坦克：`痛觉4、英勇3、持续3`；不默认点情势反转，因为稳定路线不主动被围。

## 护甲能力选择

- 默认正常通关：角斗士+英勇之跃。理由是确定性招架/清尸鬼+跨陷阱/断线/撤退，不要求卖血。
- 已有稳定逃生神器、希望角斗士远程起连：震地冲击。
- 高强化护甲狂战士、熟悉伤害窗口：苦痛坚忍；不要把红格/Boss必杀当可硬吃伤害。

## 神圣灵感

- 每阶一次+2，不改单项上限，可提前选锁定阶，解锁后点数出现。
- 一瓶默认优先T3（子职业核心）；皇冠后若T3关键点已齐或预计不到30级，优先T4。
- 不默认给T1；T2只有要同时保留刻印2、液蕴2、手起2等多个核心时考虑。

## 总默认路线

```text
T1: 老兵2 丰盛1 受衅1 钢铁1
T2: 手起2 钢胃1 液蕴2 即兴1；好刻印时改刻印1/2
子职业: 角斗士
T3: 强化2 以战3 连战1 不动2
皇冠: 英勇之跃
T4: 英勇4 二段4 堕天2
神圣灵感: 优先T3，其次T4
```

所有建议是稳定通关推导，不是官方排名；实际跨力量门槛、好刻印、强附魔、高甲和逃生神器会触发上述条件分支。
