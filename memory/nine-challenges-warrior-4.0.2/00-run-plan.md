### 探索与炼金的一页执行卡

1. **下楼前核真正缺口，不按清图比例。** 记录本区已确认力量/升级、现有战力、下一层威胁、饥饿/HP/光照、
   已知出口和未取重要资源；需要的保底可能在特殊房里，不能把“特殊房可选”误成“里面不会有升级/力量”。
2. **跳过通常指放弃本层剩余可选探索。** 首领阶段和楼梯边界仍受原生规则限制；跳坑是另一个带伤害/耗材/回收成本的方案。
   无法安全取的金币、没有明确输出窗口的追逐、低线索密室搜索应早停，别等粮光和最后脱困一起耗尽。
3. **已覆盖的普通暗门不重复搜。** 战士主动搜索仅检查本次FOV内周围1格，但对覆盖到的普通可搜秘密一次成功；
   通常2时间加4额外饥饿。沿可疑边界选最少站位覆盖，发现/覆盖完成或配额用尽便停止。
   没有公开线索时不为了理论区域配额扫完所有墙；先见护符不安不是隐藏门雷达。
4. **先保原版解谜与逃生，再转化。** 首锅通常只有实际拾到的5能量；若有原料且当前缺粮，Cleansing4E有高价值，
   传送卷拆2闪现0E可保机动。没有这些原料就用现成工具，不为凑理想配方延迟力量或饿着囤食物。
5. **同一原料只能花一次。** 唯一浮空不能同时算原版跨沟、10E羽落和12E水爆；同一Purity不能同时算环境免疫与Cleansing饱腹。
   做长期强化前先覆盖下一必经风险的最小消耗包。
6. **解控和免疫要分来源。** Purity防特定环境blob，不清/免火拳直接Burning；驱魔期间符石、杖和多数魔法逃生失效，
   不把闪现石列为此时备用退路。普通未锁层敌法精英会免疫转移的传送来源；详见15的特殊层分支例外。
7. **资源和信息分别止损。** 方案成本超预算就改路线；若遇解码失败则保留原帧、原rid和outcome，先确定原结果，
   不能靠重复动作、删公共字段或读个人存档挽救计划。

## 2. 当前战士优先核查的七个规则

1. **纹章按当前半血触发盾理解。** 普通盾看护甲阶数，150基础冷却；护甲强化不是普通盾上限。
   高阶甲仍有盾收益，但穿戴力量不足会额外恶化移动/闪避。饥饿不被盾吸收，也不触发纹章。
2. **丰盛一餐有固定直接回血。** 低于规定血线吃食物可回4/6，节食不会把这一份回血也除三。
   食物量仍有限，不能为了进入触发线主动吃危险攻击。
3. **不动如山的DR在护甲挑战公式之外。** 站位合适时十分有价值；必须移动躲远程/首领预警时放弃站桩。
4. **武器格挡也是独立防御来源。** 短棍、长棍、圆盾、巨盾等值得按真实伤害/格挡/力量预算评估，
   不能只按面板最高伤害选武器，也不能为了盾武器忽略杀敌速度和魔法威胁。
5. **角斗士可用投武起连。** 必中战技、以战养战减纹章冷却、击退和范围伤害有利于节约资源。
   这是默认研究倾向，不是已经测出的最高胜率；狂战士有可靠防伤/附魔/恢复时再比较。
6. **升级卷先解决真实门槛。** 可迁移纹章+1有保值作用；成型武器/法杖/戒指的升级要与眼前生存比较。
   不预设“永远留到T5”“永远全灌一杖”或“九挑战绝不升级护甲”。
7. **药剂使用也可能产生Barrier。** 液蕴意志的合格使用路径与投药白名单见02；Barrier取较大值而不是无限叠加。

证据与配点候选：[02 战士](02-warrior-build.md)、[06 装备](06-weapons-armor-combat.md)、[06b 附魔](06b-enchantments-glyphs.md)。

### 3.1 资源与遭遇的止损规则

止损表示收敛/取消当前活动后换计划或暂缓支线，继续遵守用户的游戏停止政策。

| 食物 | 普通口粮在节食下100饱腹，无缩时效果时进食3时间；丰盛1/2点另回4/6HP，条件严格 `HP/HT < .334`（HT25/30/35时≤8/10/11）。分开计算直接治疗、自然再生和敌方攻击 | 无铁胃先脱离近战再吃；不主动挨打凑阈值。高血饥荒进食可为恢复再生，但须有推进收益。最后一份吃完立即转向已知补给/关键资源/出口路线，停止无收益清图、追逐和等怪；未见补给不承诺可达 |

正常待输入时的源码阅读、UI检查、`state/req`和控制器`settle`不当作游戏回合；

不拿请求编号、现实分钟或任意buff显示数当通用时钟。主动搜索通常花2时间并额外加4饥饿，须另预算营养。
规则详证见复盘与01/02/03/07；`settle.timeout_ms`仅限收结果的等待，不限制游戏回合。

若原请求仍pending，先按协议消费/收敛同一请求；`response_pending`不能抢发取消或新动作。
需要取消时用当前广告的活动`rev/rid`，不能自动批量发若干`wait`或给旧决定换新`rev`。
游戏确认结束或用户要求停止时，执行其停止政策，不以“止损”为由退出、重开或另起一局。

### 3.2 整场遭遇与控制窗口：2026-10-11新增执行门槛

这一局没有rest、没有公开饥荒、临死前仍有54照明；不能只靠上一局的粮光规则解释失败。
[完整复盘与证据](../2026-10-11-warrior-nine-challenges-retrospective.md)确认两次丰盛2进食各只净回1HP，
最后困在单出口房被连续蝇群消耗。以下是策略预算，尚未证明最优或保证通关。

1. **引战前算整个队列。** 写当前HP/真实盾/冷却、武器与实际投武数量、可能增援和已知退出节点。
   短剑0、盾长冷却、无已知脱困时，主动打睡眠怪必须有明确必要收益；升级回血不抵销后来增援的成本。
2. **时限控制用来完成目标。** 恐惧或惊骇后，优先兑现穿越、断追、收尾或安全进食。
   控制窗口内不临时追加锁箱、金币或回头路。狂怒会召引全层，狂乱不保证敌人不打英雄。
3. **见到楼梯后重新批准每条支线。** 钥匙不等于奖励已到手，需知道可兑现目标和往返预算。
   每层永久资源分“已获得／已使用／已见未取／尚未定位”；区域供应配额不提供安全位置，不为凑齐而无限搜索。
4. **进食预算必须接上下一步。** 丰盛触发且这口饭不致死，只是必要条件；吃完能否脱离、控制或击杀也要成立。
   寒冷、迟缓或持续环境出现时重算时间。普通食物基础3时间，寒冷会延长；冻结还可使原生自动推进，不能保证取消窗口。
5. **免一种伤害不等于安全。** 哨兵房水格免哨兵，但不挡飞虫且只有一个出口。
   有追兵时不进单出口奖励房，除非已有杀完整队列或离开的手段；未探索空间不能计入退路。
6. **按本体、分身与后续补位分别判断。** 蝇群本体50HP；物理受击分摊剩余HP，不是每个分身新生50HP。
   门只限制同时攻击位，不减少队列总生命；同格出现新满条不得沿用刚才残血身份。还要检查身后增援。
7. **护盾和弹药不预支。** 布甲+1不增加纹章盾，钢铁意志增加未来触发上限，不立即补盾/清冷却。
   投武耐久不等于当前可发射次数；两枚石头投出后，回收安全性未成立前不算十次攻击。
8. **未知消耗品单列。** 未知药卷不算可靠控制；鉴定尽量在无敌、可承受副作用且可离开环境的窗口完成。
   排除力量/治疗不证明安全；别在低血夹击时才依靠盲读盲喝。已只能赌博时明确其风险，不虚构安全保证。

### 3.3 持续追击与可兑现战力：2026-10-11第3层豺狼人复盘

[本局完整复盘](../2026-10-11-warrior-nine-challenges-gnoll-retrospective.md)为第3层成长豺狼人死亡，
最终2级/力量10/短剑0；死亡前尚有一餐和170照明。不能套用“长休息耗尽粮光”的解释，
也不能用死后鉴定替代生前知识。以下为保守执行规则，不是已验证最优解。

1. **奖励取得后重算即时战力。** 超重鞭、鳞甲属于未来候选；没有真实力量/升级来源时不能算已补输出。
   离层审计同时列等级/经验、可用伤害、手持弹药、控制与已见未取资源；不因装备阶高就多接一场战斗。
2. **追击必须有结束条件。** 同速绕房保持距离只是在延续遭遇；计划需落实到断追、清队列、跨层隔离或实际控制。
   未知门后可能封路，不能每次都把下一个房间承诺成安全终点。也不把危险物资一概跳过：按可承受的拾取代价及后续用途逐项比较。
3. **恢复覆盖重新进入的整段风险。** 上楼+3HP的硬预算虽执行成功，再入即受4/3伤，未改变遭遇。
   同时核恢复后的敌位、盾冷却、首段路线及攻击次数；不是只保一段光或只回一个小数值。
4. **环境加工先保退路。** 试投/烹饪的即时安全、持续环境占位、等待、回收与遇敌退出是五项成本。
   缺少替代路线时，不为可选试药或加工在当前唯一通路制造寒区；用于控制敌人或必要突破时，另算完整退出预算。
   地上冻肉未取回不计入食物。来敌后允许放弃加工成果，不用最后控制补救一条尚未确认的回收链。
5. **控制成功以实际状态和结果为准。** Chilled不等于Frozen；冰霜减速后仍被追不能算脱险。
   控制窗口只执行既定穿越/断追/收尾，不加支线；完成后仍要检查队列是否已结束。
6. **安全hungry窗口也可吃。** 不必等丰盛血线或starving才利用营养；25HT时9/10/11HP都不触发丰盛1治疗。
   三时间进食要有敌人到达预算，不能把留在包里的食物视为随时可用的HP，也不能主动挨打凑阈值。
7. **清路加上退出那一击。** 击杀挡路怪后，下一格可能仍邻接另一敌人。使用当前可见词缀与源码给保守伤害余量，
   末次实伤7不能当成长怪最高伤害；不预支闪避、低伤、未触发的盾或仍在冷却的护盾。

   本局实际知识始终取当前公开观察。试用一次后先读效果、位置和状态，再决定下一份；
   水边、无人房和高HP分别只覆盖部分风险。详细候选与准备条件见18，不把未知品预支为可靠救命工具。
3. **法杖与投武进入每次战斗的动作比较。** 有安全射线就考虑先手，能少打一个近战回合就考虑收尾；
   用控场改善输出位置。计算充能、弹药回收、耐久、敌人抗性与自己的范围风险，避免满充闲置和贴脸低命中乱投。

   关键奖励、钥匙/怨灵、门外未知敌人、粮光和回程。可以先从正常楼梯探索下层公开路线再决定回跳。
   不用“会受伤”直接否定，也不只算当次直接坠落伤。精确边界见[19](19-pitfalls-and-room-payoffs.md)。
5. **信息获取先于绕路结论。** 对入口物品、书页、箱子和任务奖励，先查当前公开名称/原生说明，
   必要时核源码，明确是否强化、信息或材料，再决定是否顺手拿、专程取或延期。
   不因名称像“精通”就猜成转职道具，也不未经检查就把它长期列为低价值。

### 3.5 首领收尾、恢复负债与两步退出：2026-10-15咕噜复盘

[完整复盘](../2026-10-15-warrior-nine-challenges-goo-retrospective.md)显示主动用神器、法杖和投武有效，
但Goo从1HP恢复到78HP的重新接敌过程消耗97照明，英雄只净回11HP。以下为执行门槛，不是反事实必胜证明。

1. **恢复与重新接战合并预算。** 锁门吃饭可以安全，却不冻结Boss状态；写出重开后的目标位置、
   实际攻击终点、过水风险与照明成本。重新见到时按当前HP重算，不继续使用离视野前的“只差一刀”。
2. **LockedFloor可以负债。** 水疗扣值无下界；伤害只加回、上限50，不先归零。
   只有余额≥1普通被动恢复才可能继续。冷却／充能停住时不承诺空等可恢复，
   也不把Shock等主动补电或丰盛即时治疗一并判为无效。精确负债是隐藏值，不能从源码替本局填数。
3. **躲蓄力位还要有下一行动。** 每次至少核攻击位、当前逃格、逃后下一格；
   普通反击与Ooze另算，不预支闪避、0伤或未就绪的盾。12HP无盾邻接下半血Goo不构成可靠退出。
4. **已知收尾资源提前留。** 到残血阶段比较可命中伤害、充能、敌血与重新取得目标的成本；
   未鉴定电量、未回收投武、尚无安全窗口的食物不计为保证储备。仍需主动花资源，不改回长期囤积。
5. **短控只兑现具体效果。** 偏点冲击核推线及自身碰撞，Shock核爆点、半径、自晕与净补电。
   麻痹不保证多刀，也不停止Goo脚下水疗；未知苦无按可能超重的耗时档预算，距离2不自动免费。
6. **状态与展示不混淆。** 对Goo的`boss_warning`是半血狂暴提示，不能单独判蓄力。
   保留同帧subject及其状态文字；未绑定面板的残留HP不代替可见实体的当前HP。
   原始记录完整不能掩盖模型显示曾删掉有用UI文字的问题。

源码细节及被动恢复例外见[03 Goo](03-enemies-sewers-prison.md#goo5层绝命头目下不能多贪一刀)与复盘第5节。
这些止损要求改变计划，仍不授权在用户要求停止前自行退出、重开或重试本局。

## 6. 失控时的决策顺序

1. 判断当前帧是否完整可信、是否仍有原始pending请求；传输异常先确定原结果，不能重发动作。
2. 有公开致命预警先检查能否直接离开其实际覆盖格；走位不能穿过被怪/地形堵住的格。
3. 优先切远程线、减少同时接敌或控制最高威胁，随后才比较纯输出和治疗替代。
4. 使用应急品前确认其在九挑战下真的生效，且耗时后不会被另一威胁致死。
5. 净化移除扎根后可能让此前延迟的Yog射线恢复结算；不要在原射线上“清完再想下一步”。
6. 操作后以实际新观察重评，不能因理论上应击杀/应获得护盾便继续连发。

## 7. 仍需补充的真实经验

当前已有三局失败的完整结束证据（两局第4层、一局第3层）；**九挑战成功通关与中后期实战验证仍缺**。
本页止损建议未证明提高胜率，优先实测：

- 开局不同掉落下，丰盛/老兵/受衅/钢铁的资源回报与首区存活成本。
- 角斗士战技收尾→以战养战→纹章补盾能在何种敌人与站位上保持正收益。
- 钢铁之胃对具体首领攻击窗口的防伤与附带状态；不同伤害源的边界。
- 自然之履阳春草/治疗井/全面净化合剂的实际续航成本，是否值得回头。
- 保存载入候选的真实合法窗口、作用持续和新绑定恢复，避免只测试对象字段就宣称可稳定刷收益。
- 各种双拳组合的现场资源预算；不依赖特定神器或必掉物品的替代方案。

实玩过程中将失败与成功都记录：本来知道什么、实际执行什么、资源花了多少、为什么改计划。
不要把本次研究里的条件性方案在复盘时改写成“当时肯定能无伤”。
