**组合含义：** 防御、治疗、食物、照明和永久升级同时吃紧，持久换血及无目的清图会被层层放大。

优先建立能在实际掉落上运行的“减少受击 → 控制局面 → 少量恢复 → 继续推进”循环。

## 2. 当前战士优先核查的七个规则

1. **纹章按当前半血触发盾理解。** 普通盾看护甲阶数，150基础冷却；护甲强化不是普通盾上限。
   高阶甲仍有盾收益，但穿戴力量不足会额外恶化移动/闪避。饥饿不被盾吸收，也不触发纹章。
2. **丰盛一餐有固定直接回血。** 低于规定血线吃食物可回4/6，节食不会把这一份回血也除三。
   食物量仍有限，不能为了进入触发线主动吃危险攻击。
3. **不动如山的DR在护甲挑战公式之外。** 站位合适时十分有价值；必须移动躲远程/首领预警时放弃站桩。
4. **武器格挡也是独立防御来源。** 短棍、长棍、圆盾、巨盾等值得按真实伤害/格挡/力量预算评估，
   不能只按面板最高伤害选武器，也不能为了盾武器忽略杀敌速度和魔法威胁。
5. **角斗士可用投武起连。** 必中战技、以战养战减纹章冷却、击退和范围伤害有利于节约资源。
   这是默认研究倾向，不是已经测出的最高胜率；狂战士有可靠防伤/附魔/恢复时再比较。
6. **升级卷先解决真实门槛。** 可迁移纹章+1有保值作用；成型武器/法杖/戒指的升级要与眼前生存比较。
   不预设“永远留到T5”“永远全灌一杖”或“九挑战绝不升级护甲”。
7. **药剂使用也可能产生Barrier。** 液蕴意志的合格使用路径与投药白名单见02；Barrier取较大值而不是无限叠加。

证据与配点候选：[02 战士](02-warrior-build.md)、[06 装备](06-weapons-armor-combat.md)、[06b 附魔](06b-enchantments-glyphs.md)。

### 3.1 资源与遭遇的止损规则

以下执行规则来自[2026-10-10失败复盘](../2026-10-10-warrior-nine-challenges-retrospective.md)。
其中等待次数是可调整的保守预算，不是游戏参数或已验证最优策略；旧坐标、请求ID、药剂颜色均不复用。
止损表示收敛/取消当前活动后换计划或暂缓支线，继续遵守用户的游戏停止政策。

| 项目 | 开始前的预算 | 触发止损时如何改计划 |
| --- | --- | --- |
| 食物 | 普通口粮在节食下100饱腹，无缩时效果时进食3时间；丰盛1/2点另回4/6HP，条件严格 `HP/HT < .334`（HT25/30/35时≤8/10/11）。分开计算直接治疗、自然再生和敌方攻击 | 无铁胃先脱离近战再吃；不主动挨打凑阈值。高血饥荒进食可为恢复再生，但须有推进收益。最后一份吃完立即转向已知补给/关键资源/出口路线，停止无收益清图、追逐和等怪；未见补给不承诺可达 |
| 休息/等待 | 给出目标、最大等待预算、原生结束条件及食物/照明/退路余量。解除有限状态、等NPC/护盾或伏击，用单条 `wait`→完整响应→新决定 | 不用 `rest`假设只等5/10/20回合；不以最后口粮耗尽或照明熄灭作为默认结束点。状态已解除、达到预算、新敌/损伤或余量不足即重评。已饥荒时不靠普通再生期待回血；安全推进也能同时自然再生，但其遭遇风险另算 |
| 火把 | 本版点燃追加250照明并耗1时间；黑暗基础视距2、照明6。用完整当前图估实际通路、交互、预计接敌和撤退余量 | 照明不足以覆盖计划且无备用火把，停止可选支线/追怪/静候，转补给或出口。熄灯后的远程敌人活动区短段走；受击、中毒、传送后重做遮蔽与退路。看见两格外火把也先核守军射程，不为拾取穿致命线 |
| 诡术师 | 先核实际相邻攻击位、射线和退出路线。相邻可阻射，但等速两格追逐不构成输出；门侧初试可预算3–5次单条 `wait` | 到预算仍无实际攻击窗口便换站位或暂缓任务；新攻击窗口或物质条件变化可重估剩余上限，但保留累计耗时与粮光成本，不清零续等。无可验证攻击终点、受击/毒、新敌或余量不足时停止追加诱敌/追逐；已有相邻窗口按当前伤害与退路另作战斗决定。逃跑可侧移/短暂靠近，游荡不保证返门；有物品堆的门不自动关闭，投射遮挡、双方FOV、偷袭分别核查 |
| 未知药剂 | 提前安排鉴定并保留排除项；排除“力量”不证明安全。常规试饮须能承受不利结果，附近无敌且有离开气体范围的路线；干地/水格单独都不保证安全 | 无存活与撤退预算就停止常规试饮。低血、饥荒、夹击时不把未知饮用列为默认保命；先比较当前已知控制/移动/战斗的一回合后果。若只能赌博，明确可能麻痹自动推进、不返回可行动帧，或冻结/碎瓶连锁；不能承诺喝后还能取消。死亡鉴定与跨局颜色不作当时知识 |
| 换层/退路 | 合并检查HP、当前盾、`counter_kind`、粮、光、已知脱困工具和连通出口；物品与怪物同格、窄门、射程分别检查 | 多项余量不足时提前压缩可选任务，不等耗尽才推进。`cooldown:4`不是4点盾；饥饿不吸盾、不触发纹章。未知地图不补成安全通路，巨型怪不能进窄门也不保证门内两格安全 |

正常待输入时的源码阅读、UI检查、`state/req`和控制器`settle`不当作游戏回合；
持续休息、旅行、麻痹等原生阶段仍可能推进。照明计数与已验证的护盾冷却只能在相应本版条件下核成本，
不拿请求编号、现实分钟或任意buff显示数当通用时钟。主动搜索通常花2时间并额外加4饥饿，须另预算营养。
规则详证见复盘与01/02/03/07；`settle.timeout_ms`仅限收结果的等待，不限制游戏回合。

若原请求仍pending，先按协议消费/收敛同一请求；`response_pending`不能抢发取消或新动作。
需要取消时用当前广告的活动`rev/rid`，不能自动批量发若干`wait`或给旧决定换新`rev`。
游戏确认结束或用户要求停止时，执行其停止政策，不以“止损”为由退出、重开或另起一局。

## 5. 弹道和特殊技巧的执行门槛

**有遮挡时的投射顺序：**

1. 当前帧定位英雄、目标、全部已知阻挡与角色；核实具体物品的碰撞模式。
2. 先算直接点敌人的路径和碰撞；若失败，尝试已知的其他瞄准格，检查离散射线是否先穿过目标。
3. 对冲击、雷霆、焰浪、腐蚀、解离等，再检查击退/电链/锥形/落点/穿透的二次效果。
4. 不能用反向路径代替正向，也不能用“视觉连线穿过”代替离散格序列；未知格停止确定性预测。
5. 只在当前操作允许所选格时出手，立即按成功回复重评。例子中的坐标只属于合成地图。

[08](08-ballistics-and-wands.md)保存原版Java验证过的绕障碍、方向不对称与改击退方向例子。
现有公开地图助手的限制也在该页；不为尝试射线读取地图私有数组或个人存档。

**退主菜单再继续：** 不作为修复未知请求结果、回滚挨打、恢复HP/冷却/充能或重新生成地图的默认办法。
09已识别并隔离验证某些临时字段改变，但实际战术还需合法的退菜单时机和公开结果。
特别是变鼠计时、重型回旋镖返航、DM-201反应状态的候选，不保证每种局面都有可利用窗口。
详见 [09](09-save-reload-state.md)；未来需要实测时用隔离新档验证，再决定是否纳入正式跑法。

## 6. 失控时的决策顺序

1. 判断当前帧是否完整可信、是否仍有原始pending请求；传输异常先确定原结果，不能重发动作。
2. 有公开致命预警先检查能否直接离开其实际覆盖格；走位不能穿过被怪/地形堵住的格。
3. 优先切远程线、减少同时接敌或控制最高威胁，随后才比较纯输出和治疗替代。
4. 使用应急品前确认其在九挑战下真的生效，且耗时后不会被另一威胁致死。
5. 净化移除扎根后可能让此前延迟的Yog射线恢复结算；不要在原射线上“清完再想下一步”。
6. 操作后以实际新观察重评，不能因理论上应击杀/应获得护盾便继续连发。

## 7. 仍需补充的真实经验

当前已有一局第4层失败的完整结束证据；**九挑战成功通关与中后期实战验证仍缺**。
本页止损建议未证明提高胜率，优先实测：

- 开局不同掉落下，丰盛/老兵/受衅/钢铁的资源回报与首区存活成本。
- 角斗士战技收尾→以战养战→纹章补盾能在何种敌人与站位上保持正收益。
- 钢铁之胃对具体首领攻击窗口的防伤与附带状态；不同伤害源的边界。
- 自然之履阳春草/治疗井/全面净化合剂的实际续航成本，是否值得回头。
- 保存载入候选的真实合法窗口、作用持续和新绑定恢复，避免只测试对象字段就宣称可稳定刷收益。
- 各种双拳组合的现场资源预算；不依赖特定神器或必掉物品的替代方案。

实玩过程中将失败与成功都记录：本来知道什么、实际执行什么、资源花了多少、为什么改计划。
不要把本次研究里的条件性方案在复盘时改写成“当时肯定能无伤”。
