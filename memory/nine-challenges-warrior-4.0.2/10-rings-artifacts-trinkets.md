# 10：戒指、神器与饰物——九挑战战士资源构筑

适用基线：仓库提交 `8405ae82f`，游戏 4.0.2 / code 922，2026-10-10 静态源码研究。以下“确定”只表示该版本实现可支持，不表示已经在九挑战实局验证。没有启动游戏、读个人存档或私有审计，也没有推断未来掉落。源码链接从本文件回到项目根目录；行号属于此基线。

本章覆盖生成目录中的 **12 种戒指、13 种神器、17 种饰物**。其中暗影斗篷与神圣法典的普通生成权重为 0，普通战士不能把它们写进掉落计划；此外两个旧神器类仍留在源码，另列说明。这里的优先级是源码机制推导，实战必须根据实际获得物品、诅咒状态、层数与升级余量选择。

2026-10-14补充：按用户要求积极获取、装备并使用神器的执行表见[17神器获取与使用](17-artifact-acquisition-and-use.md)；本轮同步校准下表圣杯饥饿阶段、沙漏库存生成条件和工具箱预热时序。

## 一、先确定投资方式

- **戒指**占戒指或杂项槽，可以用升级卷轴；九挑战卷轴稀缺，优先把升级转化为少挨打、远程击杀、可重复控制，不能只看面板伤害。
- **神器**占神器或杂项槽；按各自机制成长，普通升级卷轴不能升级。自然之履、锁链、沙漏的内部等级上限并非 10，但 UI 会映射成 +10。两个同类神器不能同时装备。神器一经成功装备即鉴定；随机普通神器初始 +0，通用随机诅咒率 30%，并非某一次拾取的已知事实。[Artifact.doEquip/isUpgradable/visiblyUpgraded/random](../../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/artifacts/Artifact.java#L65)
- **饰物**只需在背包里即可生效，不占装备槽；通常本局只选择一个，炼金升级到 +3。不能把饰物效果误作“装备后才开”。[Trinket.trinketLevel/UpgradeTrinket](../../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/trinkets/Trinket.java#L50)
- 时间充电型神器多检查 `Regeneration.regenOn()`：它只检查锁层规则，没有“饥饿就停止充电”的条件。**饥饿时可能仍充电，但等待仍造成饥饿伤害、刷怪与火把损耗**。号角、工具箱、袖章的主要充电是获得英雄经验进度；不要用休息期待它们自动充满。[Regeneration.regenOn](../../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/actors/buffs/Regeneration.java#L113)

财富的关键边界：普通怪/小首领/首领分别给额外掉落计数 1/5/15 次；一次额外掉落后重抽 `NormalIntRange(0,20)` 的间隔，装备奖励之间通常要经过 5–10 次额外消耗品奖励；它不是随着戒指等级线性加快这个计数。装备计算限制第二枚财富戒贡献最多 2；单枚 +L 的可升级奖励最低等级为 `floor((L+1)/2)`，例如 +3 戒指最低 +2 装备。奖励具体类别、到达时间仍随机。额外装备会清普通诅咒、标已知无咒；神器不直接获得相同数值升级。[Wealth 装备贡献和过滤](../../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/rings/RingOfWealth.java#L133)、[装备最低等级](../../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/rings/RingOfWealth.java#L270)、[Mob.rollToDropLoot](../../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/actors/mobs/Mob.java#L1097)

鉴定戒指通常需要戴着累计约一个英雄等级的经验，受鉴定天赋倍率影响；这是经验进度，不是穿戴一回合。遗忘碎片会将自动鉴定改为“已可鉴定”。升级戒指只有 1/3 概率解除诅咒，不能把珍贵卷轴当作必成功的祛邪替代品。[Ring.onHeroGainExp](../../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/rings/Ring.java#L329)、[Ring.upgrade](../../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/rings/Ring.java#L228)

## 三、11 种普通可生成神器及两种职业专属神器

全部 11 种普通神器来自同一唯一性池，每种标准权重 1；生成后扣除该种权重。本章不声称在哪层必出哪件。获得方式可为正常战利品或原生嬗变等，但可用池仍制约结果。已升级神器嬗变保留**显示等级**和诅咒状态，不能靠嬗变自动洗咒；失去原神器就是实际资源变更。[Generator.ARTIFACT](../../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/Generator.java#L560)、[randomArtifact](../../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/Generator.java#L855)、[changeArtifact](../../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/scrolls/ScrollOfTransmutation.java#L295)

### 圣杯：用最大伤害预算，不能靠警告概率赌博

从现等级 L 刺向 L+1，原始伤害是 `NormalIntRange(ceil(3+2.5L²), floor(7+3.5L²))`；例如 L0=3–7，L3=26–38，L6=93–133，L8=163–231，L9=206–290。代码手动经过地缚护甲、活土岩甲、英雄DR等，再至少保留1点，之后才进英雄伤害流程。无甲降低DR、恐药症让回收刺伤困难；圣杯的成长不是“无耗升级”。只在已观测HP/盾、真实减伤、下一次安全恢复和敌人行动全部足够时考虑一次刺血。不要根据期望伤害判断存活，也不要把额外保护法术当成战士必得。[Chalice.prick](../../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/artifacts/ChaliceOfBlood.java#L121)

### 袖章与钥匙：避免把永久损失误算为免费

袖章偷商店按物品原价值而非展示购买价计算：每充能提供 `10+L/2` 的价值，使用不超过当前充能的必要数量，成功率 `min(1,总价值/item.value())`。只有界面已显示100%才能按确定成功预算；低于100%失败会令商人逃离。偷怪不重复创造同一怪的基础物品：`StolenTracker` 标记一次尝试，成功后击杀不会再掉同一基础物品。[Thievery.stealChance/chargesToUse](../../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/artifacts/MasterThievesArmband.java#L299)

钥匙神器用电打开锁后，会跟踪该层尚需钥匙数并丢弃多余普通钥匙，不是一个“保留钥匙并无限开箱”的复制器。用5充打开额外水晶选项可以创造选择收益，但仍须核该房间的具体原生门/箱交互，以及随后有无急需的2充墙/锁门逃生储备。[KeyReplacementTracker](../../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/artifacts/SkeletonKey.java#L615)

旧类 `CapeOfThorns`（荆棘斗篷）、`LloydsBeacon`（时空道标）仍存在，但**不在当前 Generator.ARTIFACT 列表中**。旧档兼容类的反伤/设点传送机制不能作为本次新战士九挑战的可获得构筑。没有为不可正常生成的旧类设计刷取路线。

## 五、可带入实战的组合优先级

这些是**有相应掉落时**的决策方向，不是要求通过重开或存档读取定向获得。

1. **疾速 / 神射 / 控制法杖 + 锁链或沙漏**：降低被近身、被群攻和强首领连打的概率，九挑收益通常比单純提高护甲稳健。输出与位移分别留应急电量；不会因单次射线可达就证明后续仍安全。
2. **自然鞋 + 阳春草/速行蓟 + 能量戒**：荒芜仍可直接用种子效果，最值得在掉落后重新制订路线的组合。石化种子与鞋兼容，但减少种子占比；苔藓提供更多高草、代价更高。先保留关键种子，再决定炼金/喂鞋，不应为升级鞋把全部药剂原料吃光。
3. **号角 + 战士进食天赋**：用小份snack触发一次进食收益；九挑每充仅30饱食，需区分“战士天赋的直接收益”和“食物续航”。充能取决于经验，早期投入食物须算将来还剩多少升级进度。
4. **奥术 + 适合的控制附魔/刻印**：实际已有附魔才投资，不按未来肯定会出投卷；升级过高可能损失原附魔/刻印，详见装备章节。残魔余卷+3增加未来随机附魔装备来源，但前期诅咒与51能量可能比收益更早到来。
5. **盐晶 + 非自然回血来源 / 少受伤路线**：用更长饱食减轻食物短缺，配鞋Health、战士进食等；有盐晶时等待自然回血慢40%，不要把饱食时间翻倍误当即时回血翻倍。
6. **财富 / 遗忘碎片 / 巨鼠头骨 / 拟箱利齿**属于资源风险投资：前两种也要求当前能稳定杀敌，后两种直接加重遭遇风险。九挑已有精英、蜂拥、禁疗，先证明当前资源能覆盖新增敌人，再讨论更高掉落。高等级后怪物不再掉落时，不能继续套“无限刷物”。

## 六、实战检查与验证边界

- 新神器先读公开鉴定/咒状态、当前充能、可用动作；神器一经装备虽鉴定，但如果诅咒会卡槽，须在安全点且有祛邪方案时试穿。
- 用神器前同时算当前敌人行动、占格、移位终点、消隐、耗时、使用后电量；钥匙墙/锁链/时间气泡会改变局部路径与弹道，下一步必须重新观察。
- 本章已核对三类全部生成目录及具体实现入口。未做任何实局、战斗模拟或独立fixture验证；尤其袖章零显式耗时在完整动画/控制调度中的可见行为、钥匙墙和各敌人特殊穿墙攻击的交互、香炉正负气体在特定格局中的净收益，须在获授权实战中按公开结果谨慎确认。
- 重入主菜单不会把已消耗种子/食物/卷轴还原，不应把神器刷新经验当既成技巧；魔典选项和饰物选项有明确保存/恢复措施。关于其他场景重入的可利用变化，读本研究的重入章节。
