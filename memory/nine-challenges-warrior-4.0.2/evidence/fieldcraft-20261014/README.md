## 核验方式与证据等级

- **当前源码复核：** 每个专题读取实现及关键父类/调用链，正文就近链接源码行号。
  不能只由物品说明、旧攻略或源码中的遗留注释给出数值。
- **独立语义复核：** 另行复核了跳坑/流血/盾/跨层、净化试药、未知目标卷取消、神器充能/激活、
  投武升级/旧件、法杖伤害/免疫/充能等关键路径。审查不证明所有地图组合或全部行动时序。
- **静态链接与来源指纹：** [verify.py](verify.py)检查整个研究库及项目memory索引的本地链接与源码行号范围；
  [source-manifest.json](source-manifest.json)只绑定本批五份新专题及其直接引用来源的SHA-256，
  并检查这些来源内容与上述源码提交相同。结果见[validation.json](validation.json)。
  链接存在不等于结论正确；这些数字表示引用规模，不代表逐行形式化验证。
- **有限算术：** [pit-budget-formulas.py](pit-budget-formulas.py)输出7组直接伤害/前三次流血tick预算、
  3组纹章盾触发例子，并记录5份输入源码指纹。[pit-budget-results.json](pit-budget-results.json)
  是纯公式结果，按Java float与正数四舍五入处理关键输入；没有运行引擎、抽样随机或加载玩家。
  三个tick不等于三个英雄动作，也不表示完整流血只有三次。复算记录见[arithmetic-check.json](arithmetic-check.json)。

## 与旧基线的关系

本次改动前，旧[verify_research.py](../verify_research.py)检查27份Markdown、2013个本地链接、1851个行号锚点，
没有报缺失链接或非法行号，但在656份引用来源中报告31项源码/引用集合相对旧清单变化。
这是2026-10-10指纹与后续CLI维护/文档增补的已有差异；不能据此宣称旧整库指纹检查通过，
也不为得到全绿结果覆盖旧[source-manifest.json](../source-manifest.json)。本批使用独立清单，
原始研究、旧fixture和旧验证数量继续保留。今后源码改变时，需重新核具体变化，而非机械更新SHA。
