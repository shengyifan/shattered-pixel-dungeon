## 复现方法

2026-10-14的主动神器、药卷、跳坑、投武与法杖研究使用独立的
[本批证据与核验](fieldcraft-20261014/README.md)。新来源清单绑定`bb0c91fb7`，
保留本页早期基线及原始fixture；不能把本批静态复核和纯算术写成新的实局通关或旧清单全量复验。

在仓库根运行：

```sh
python3 memory/nine-challenges-warrior-4.0.2/evidence/run_ballistica_examples.py
python3 memory/nine-challenges-warrior-4.0.2/evidence/reload/run_probe.py
python3 memory/nine-challenges-warrior-4.0.2/evidence/verify_research.py
```

- 弹道工具从当前源码复制未修改的Ballistica.java，在临时目录编译，完成后清理；只打印合成结果。
  完整冻结结果在 [ballistica-native-results.json](ballistica-native-results.json)，包含源码、runner指纹和Java版本。
- 保存夹具要求先有本版本的`desktop-control/build/test-runtime-classpath.txt`。脚本不自动重建产品；
  只把研究类编译到仓库忽略目录`build/research-reload-fixtures/`。缺classpath会直接报错。
  [result.txt](reload/result.txt)保存21份源文件及两个runtime JAR的指纹。
  改过源码后，旧JAR可能失配，必须按项目正常构建流程准备匹配runtime再运行，不能只看PASS。
- [verify_research.py](verify_research.py)默认只验证链接/源文件指纹。
  `--write-manifest`用于有意更新已复核的引用清单；它检查游戏源码仍与本次基线相同。
  更新到新游戏版本应重新研究并另建版本目录，不机械覆盖旧结论。

## 证据解释

“全部挑战511”只表示隔离对象在此挑战标志下执行，不意味着已跑完九挑战。
“源码字段会重置”不表示输入窗口一定存在，也不表示已经结算的攻击/伤害会回滚。
“几何射线可达”不表示当前观察有该目标、物品可使用、对方没有免疫或释放后能活下来。
未来实战的新增证据应包含实际公开响应、动作、资源变化和结果，保存到独立记录并链接相关规则页。
