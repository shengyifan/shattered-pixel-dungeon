本局在第4层被蝇群杀死，未通关。**主要失误是遭遇管理和资源兑现：控制生效后追加支线，
缺少稳定输出与脱困工具时继续引战，把“这一步不会死”误当成“能撑完整场战斗”。**
最后未知药剂、冻结与连续近战放大了问题，但并非整局失败的唯一原因。

## 3. 关键决策失误及其实际代价

### 3.1 二层：恐惧争取了通行时间，却在追兵未解决时追加支线

`t1.351` 恐惧石使巨型豺狼人恐惧，英雄23/25、照明94。
经过主通路后，又进入东侧草地房，查看没有当前开锁条件的锁箱支线，再回门口：
`t1.374` 照明68，金币仍98，库存没有新增。整个恐惧后区间耗26时间；
其中到 `t1.361` 已到通路节点、光82，此后折返到374又耗14，不能把全部26都算成纯支线。
巨型豺狼人于384再次追近。恐惧只是时限控制，不是消灭敌人。
[StoneOfFear](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/stones/StoneOfFear.java)
的20时长不支持带着追兵慢慢补全房间。

爆炸石384确实击杀前方普通豺狼、打开通路，这是有效消费。
但继续进入尚未确认能穿出的书房时，门内有豺狼、背后有巨型怪与蛇。
狂怒404后在门口连打405–408，生命 **19→15→12→9→5**，中途还消耗了触发的纹章盾。
狂怒使部分敌人互斗，却没有保证英雄不挨打：
[ScrollOfRage](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/scrolls/ScrollOfRage.java)
会召引全层敌人，视野内狂乱目标仍按各自视野和可达性选择目标。
“给多人狂乱”不能直接当作三个安全吃饭回合。

随后嬗变未知卷获得惊骇、赶走投射冠军、吃熟肉、用直觉鉴出并喝力量药，都是实际救回局面的收益。
但这条救场链依赖当时未知卷的结果，不能当成未来稳定方案。
450盲读另一张卷得到报复，伤害/致盲巨型怪同时给自身虚弱和失明；又增加了离开难度。
当时楼梯尚未发现，不能批评成“看见楼梯却不下”。准确失误是**没有给控制后的路线限定终点与最大成本**。

**改进：** 使用时限控制前写清“穿过哪段已知路、在哪个节点重评、若节点不通用什么退出”。
未摆脱追兵时暂停新房、锁箱、金币绕路；控制到期前必须已经实现穿越、拉开、击杀或第二层控制之一。
发现房内堵路立即把它当作多方接敌问题，而不是默认门内安全。

### 3.2 三层：已见出口后，为未取得的水晶钥匙追加遭遇

`t1.565` 已看见楼梯272，生命18/30、照明166、食物2口粮+馅饼。
566转向水晶钥匙74，568停在176时遇见满血蝇群207；钥匙最终没有取得。
退回门侧211后持续战斗，后方普通豺狼又加入，形成前后接敌。
到589为14/30+盾2、光144；593下楼光139。**从已见出口到下楼耗27照明，净失4HP，
获得部分经验但没有钥匙。** 不能证明直接下楼绝无遭遇，但此次额外支线没有兑现目标。

这里也不能把所有门口战斗都判错：先杀后方豺狼、蛇，门口处理分身，最终放弃第二只满血蝇群下楼，
都是局势已恶化后的合理收敛。真正该提前改变的是支线的进入条件。

另有独立、可确认的执行失误：499向716投石被墙截住，石头落回英雄783附近，没有伤到成长冠军。
这是离散弹道判断错误，后来507回收了石头，不能说永久损失一枚；实际代价是空耗一次投掷和失去开战伤害。
应在有墙角时使用当前完整公开帧运行
[ray.py](../skills/pixel-dungeon-run-assistance/scripts/ray.py)，而不是凭坐标连线想象路径。

**改进：** 楼梯已知后，额外支线必须能说明它解决哪个当前缺口、拿到后怎么退出、失败时何处止损。
“地上有钥匙”不是收益已经实现；还要计入对应门/箱的未知位置、守军与第二次回收路程。
短剑0、缺少可靠脱困且不能迅速处理守军时，不把高血量敌人附近的可选钥匙列为默认下一站；
本次565的18/30仍高于半血，不能将后来14/30倒灌到支线决策前。

### 3.3 四层：没有后续战斗储备，主动攻击睡眠史莱姆

603时英雄15/30，盾冷却99、光130，史莱姆1223睡眠。
606、609把仅余两枚投石先后打出，分别造成4、2伤害，石头落在1223/1222，需要到场回收。
投武耐久不等于手中弹药次数；两枚石头不能在无法回收时当十次远程攻击。
击杀史莱姆613后升级到20/35，但近处已有两蝇群与螃蟹。

615在接敌时盲读GYFU，实际是充能；背包没有法杖，未形成即时输出或控制。
虽然这一步没有扣生命，照明124→123、螃蟹从1123逼近1071，仍消耗了敌人行动时间。
撤到北门再打蟹，613→625生命 **20→7**、光124→113；盾还没有转好。
事后可判断这次盲读未产生所需收益，但未知身份本身并不支持事前知道一定无效。
问题是直到敌群近身才把未经鉴定的卷轴作为控制计划。

[Swarm Intelligence](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/actors/mobs/Mob.java#L317)
是持续看见目标时扩大近处召引范围，初始2、每时间加2、上限12，**不是任何战斗瞬间召来全层**。
公开tracker显示的数值是警报范围，不是剩余回合或敌人数。
因此不能凭事后结果说“攻击史莱姆必定唤来这三只”，但九挑战下主动开战本来就应预算增援。

**改进：** 引战前评估“当前敌人+可能增援+撤退中追击”，不只算第一只会不会掉血。
如果开场投石都落在敌侧、护盾未好、没有确定控制，只有获得明确关键资源或无法绕过的战斗才值得承受。
先在已知区域布置门侧和退路，再决定是否引出敌人；未验证的北方门不能充当已知脱险终点。
等级4得到天赋点后及时评估分配；临死前才加钢铁意志不会立即补盾或清冷却。

### 3.4 食物：五次都满足丰盛血线，但“能吃完”不等于有效脱险

本局已经取得的五份食物最终全部吃掉，且五餐都满足丰盛触发阈值；
这不表示所有地面食物都取到，四层已见的1370口粮没有拾取。
[Food](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/food/Food.java#L74)
在本阶段基础耗时3；节食把营养除三，不除丰盛回血。
[Talent.onFoodEaten](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/actors/hero/Talent.java#L587)
在严格 `HP/HT < .334` 时，丰盛1/2分别回4/6；35最大生命的阈值是≤11。

| 413／2层 | 口粮，丰盛1 | 5→8/25 | 47→44，3时间 | 有4治疗，但新投射冠军射中2；净+3含其它结算，不能称安全三回合 |
| 421／2层 | 熟肉，丰盛1 | 6→10/25 | 41→38，3时间 | 惊骇已控制可见投射敌人，实际得到完整4治疗 |

630时只让一只普通蝇群接敌，把其伤害1–4纳入三次攻击，能估算“这次进食仍可能活着”。
但吃完仍有两只蝇群与炽焰史莱姆追击，后续物理交战还存在分裂风险，没有完成断追、击杀或安全换位。
638重复同样方式，继续拿有长期饱腹价值的食物换很少的即时生命。
营养和后续再生仍有价值，不能说整份食物毫无收益；失误是没有把收益连接到一个可执行的退出计划。

**改进：** 常规进食先取得安全窗口；被迫战斗中吃时，同时写出吃完的下一步，
确认能离开、完成收尾或把敌人控制到下一次行动。仅通过“本次最大伤害不会致死”不足以批准连续吃。
不主动挨打凑血线，不为等丰盛而把高血饥饿推进到不可控局面。

### 3.5 单出口哨兵房：水格避开一种伤害，却没有结束追兵

653在10HP时进入红色哨兵奖励房门406，654到水356；一只满血蝇群占门，另一只在后。
源码 [SentryRoom](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/levels/rooms/special/SentryRoom.java#L253)
只在英雄位于本房特定地板14且处于哨兵视野等条件满足时攻击；水格确实让哨兵重置蓄力。
[SpecialRoom](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/levels/rooms/special/SpecialRoom.java#L47)
限制一条连接，**这个免哨兵伤害的位置仍是单出口战斗死角**。
本局没有证据显示哨兵造成伤害，不能把死亡归给踩红地板。

656在水上喝未知magenta，实际为冰霜，英雄和门口蝇群都寒冷。
658继续在寒区吃饭；反馈出现双方Frozen、治疗瓶冻碎。
英雄10→17，是实际回血与控场收益，冰霜不是立即杀死英雄的药。
但光91→67、盾冷却60→36共同说明返回下一可行动观察前经过24时间。

[Chill.speedFactor](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/actors/buffs/Chill.java#L45)
与 [Char.spend](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/actors/Char.java#L1167)
会延长普通动作时间，最慢可翻倍；
[Freezing](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/actors/blobs/Freezing.java#L68)
在水上累积寒冷并转冻结；[Frost](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/actors/buffs/Frost.java#L52)
使角色麻痹并可能冻碎药瓶；[Hero.act](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/actors/hero/Hero.java#L860)
在麻痹时继续自动耗时。
图标显示整数5不是底层精确冷却，不能据此断言这口饭单独恰耗6，也不能把24全部归给食物。
该请求最终同步 `completed`；不能事前保证麻痹后一定有机会靠取消打断。

666–667连两次攻击落空，寒冷仍延长动作；到668，17HP已降到9。
672杀死首只蝇群、经验4→7，但406随后又显示另一只满血蝇群，旁边还有分身。
到676剩2HP，677攻击后受到2物伤死亡。
[Swarm](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/actors/mobs/Swarm.java#L45)
本体50HP、伤害1–4，物理受击在有空四邻格时分摊剩余生命给分身，分身经验0。
这不是“每个分身复制50HP”，门口满条重新出现也不是同一只回血；是后续本体补位。

**改进：** 将危险房分为“能避某机关”和“能脱离整场遭遇”两项独立判断。
追兵尚在时，不把单出口奖励房当撤退终点，除非已有杀完整队列或离开的确定手段。
未知药常规鉴定应在无敌、可离开气体/火/寒区、可承受副作用的条件下完成；
排除力量/治疗/火焰不等于排除危险。若已只能赌博，要承认没有可靠退路，不能把猜测包装成安全操作。
喝后出现减速、冻结环境等新条件，立刻废止此前的三回合进食预算。

## 4. 全九挑战战士的资源与战斗规则

### 永久战力优先，但不能用死亡后信息补出装备

本局直到死亡仍短剑0、布甲1、力量11。首张升级给布甲与纹章**可解释但有机会成本**：
[Armor.DRMax/DRMin](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/armor/Armor.java#L379)
在护甲挑战下让布甲0–2变0–3，降低力量要求，并保留首升级迁移价值。
但 [BrokenSeal.maxShield](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/items/BrokenSeal.java#L95)
是 `3 + 2×护甲阶数 + 钢铁意志点数`，**强化等级不增加这份盾**。
不应写成“升级布甲完全无用”，也不能默认它比提升输出更适合当前开局。

下一局每张升级都比较：眼前减少几次敌方攻击、可穿戴门槛、纹章迁移价值，以及下一危险遭遇。
没有合适高阶装备时也应比较可立即用的武器/法杖/戒指；不能一直把未来好装备当作已获得的战力。
本局在第4层结束、楼层存档已删除，不能证明某件更好的装备必能安全取得。
按 [Dungeon.posNeeded/souNeeded](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/Dungeon.java#L542)
及 [Level.create](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/levels/Level.java#L224)，
首区1/2层合计安排一瓶力量，3/4层合计再安排一瓶；禁忌咒文保留原三个升级槽的第1与第3槽，首区共两张。
计数在生成时增加，不会因没拾取就到下层补发。因此本局只兑现一瓶力量与一张升级，确有永久成长缺口。
但物品可能在尚未公开的区域或特殊房，区域配额不能反推出当时未见物品的安全坐标，
也不能证明为了补齐资源冒险回头一定比当前路线好。

### 每层与每场遭遇各做一次短预算

| 资源 | 决策前必须写下的事实 | 本局对应的止损规则 |
| --- | --- | --- |
| 生命与盾 | HP/HT、真实shield、盾冷却、是否饥饿、是否减速；把盾数和冷却数分开 | 仅剩2盾不当完整下一战储备；盾cd未好，不因加钢铁意志就预支新盾；不为等150冷却无目的耗粮光 |
| 输出 | 武器、力量、可命中率/DR、现有远程发射次数、能否回收 | 两枚已落地投石不算库存；满血50HP蝇群不是普通小怪收尾；不能用连续必中估计战斗长度 |
| 食物 | 数量、节食营养、丰盛阈值、进食速度、吃完以后能做什么 | 两次净+1仍被追时，不能再把食物当完整逃生手段；冻寒状态使旧进食预算失效 |
| 光照与路线 | 当前照明、备用火把、已知通路长度、返回/开门/拾取/战斗成本 | 地图很大时压缩可选支线；火把在鱼边先算取回风险；本局跳过危险鱼边火把合理 |
| 消耗品 | 已知控制/位移及适用敌人，未知物单列；兑现一次后还剩什么 | 最后一件脱困用完即降低引战和支线预算；不要把未知卷、未找到的炼金锅或门后空间计入可靠退路 |
| 永久资源与金币 | 已确认力量/升级、可用装备、必需目标和金币的当前用途 | 未到商店的558金币不能代替即时战力；便路拾取可做，高风险绕路捡钱不能自动优先于出口 |

这是策略预算而非固定血量门槛。不能宣布“有20HP就能打”“低于一半必须下楼”，
因为敌人、射程、装备、地形和下一层入口都改变风险。
下楼同样是一次遭遇决策；在三层已失去控制储备的情况下，四层应该降低主动开战意愿。

### 战斗按整个队列计价

1. **先认词缀和射程，再选门。** 巨型不能穿窄门不等于门内两格不受击；投射冠军也不能按相邻近战估算。
2. **检查前后两端。** 门能限制当前正面攻击位，挡不住后路加入的豺狼，也不能消除蝇群本体的总血量。
3. **每次减员后重新识别。** 对照名称、状态、血条和新位置；同格新满条敌人可能是后续补位，不沿用刚才的残血判断。
4. **蟹优先避免裸追逐。** [Crab](../core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/actors/mobs/Crab.java#L34)
移动速度2、伤害1–7、DR0–4；移动快不等于每回合攻击两次。准备好的门口收尾可行，边探未知路边让蟹贴身则高代价。
5. **控制要兑现成进展。** 恐惧、惊骇、狂乱、寒冷都有不同目标/时长/副作用；用后优先穿越、断追、收尾或安全进食，不马上恢复可选探索。
6. **升级回血和天赋不能预支。** 本局杀史莱姆得到5最大生命与回血，但随后的蟹队列耗13生命；升级不能证明下一场可承受。

## 5. 哪些做法保留，哪些结论暂不成立

应保留：全程依据公开记录逐次操作；九次STALE_STATE均查到原请求REJECTED后重观测，没有重放未知结果；
爆炸石清路、惊骇对投射冠军、正确触发丰盛、提前续火、避开鱼边危险火把、三层放弃第二满血蝇群，
以及确认本局结束后停止操作。这些是局部有效决策，不因此抵销前面的风险累积。

随机结果包括多次miss、伤害浮动、未知卷的具体身份和新区域敌人组合。复盘应要求为miss和增援留余量，
不能把所有坏结果定性为操作错误，也不能因为惊骇救过一次就推荐复制盲卷链。
尚未证明：给短剑先升级一定胜过纹章、提前加钢铁意志一定保命、不喝冰霜一定能逃、某箱必出救命装备。
本局没有使用现成炼金台，因此“早点把治疗瓶炼成资源”只能是找到锅后的优先级，不能虚构成当时漏按的按钮。

每次进食明确下一步；离层前承认真实战力缺口；进入单出口前证明退出方法。
